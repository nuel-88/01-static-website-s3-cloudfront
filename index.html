AWS Cloud Practitioner · Project 1

Static website on S3 and CloudFront

This page is an object in a private Amazon S3 bucket, delivered through Amazon CloudFront with Origin Access Control.

What this lab proves

  • Object storage can host a site without Amazon EC2.
  • The bucket stays private; only CloudFront can read objects.
  • Viewers use HTTPS at the edge.

Services in play

Service Job
Amazon S3 Origin object store
Amazon CloudFront CDN, TLS, caching
IAM / bucket policy Allow CloudFront only

Tear down the distribution and bucket when the lab is finished.
